# Product screenshot

`report-list.png` shows the actual React report list with synthetic acceptance
data. It is a copy of an existing local capture without pixel edits, not a mockup.
The capture was made on 2026-10-28 at 1440 pixels wide as a full page.

The source was `.local/design-review/reports-1440.png`, generated by
`web/e2e/review.spec.ts` through `checkDesign` in `web/e2e/design-check.ts`.
`review-admin`, `1.1.1.1`, and `abuse@example.net` are synthetic fixture values,
not an operational account, attacker address, or report recipient.
The image was inspected against fixtures without rerunning E2E. The capture does
not prove a full E2E pass or production verification.

## Capture again

1. Check dependency and browser requirements in the [frontend instructions](../../web/AGENTS.md).
2. Run `npm --prefix web run test:e2e` at the repository root. Use only the runner's
   loopback API and isolated DB. Preserve storage guards.
3. Inspect the new `.local/design-review/reports-1440.png`. Confirm it contains no
   production data or secrets and is not loading or showing an error. Then copy
   it to `report-list.png` in this directory.
4. Update the capture date and check the README image and description.

Never label an old image as a new capture after a failed run. Do not connect real
sensor addresses or production databases to create a screenshot.
